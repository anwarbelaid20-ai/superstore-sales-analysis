# Superstore Sales Analysis

## Project Overview

This project analyzes the Superstore dataset to identify sales performance, profitability, customer behavior and regional trends.

The project follows a complete data analytics workflow:

**Python → Data Cleaning → SQLite/SQL → Power BI → Business Insights**

## Objectives

- Clean and validate the raw dataset
- Prepare reliable data for analysis
- Perform SQL-based analysis
- Analyze sales and profitability
- Identify top-performing customers and regions
- Analyze the relationship between discounts and profit
- Build an interactive Power BI dashboard
- Extract actionable business insights and recommendations

## Project Workflow

### 1. Python – Data Cleaning

Python and Pandas were used to:

- inspect the dataset

- handle corrupted rows

- create the cleaned dataset

- total sales

## Key Insights

- Technology is the strongest category in terms of sales and profit.
- West is the most profitable region.
- Higher discounts do not consistently lead to higher profits.
- Customer profitability varies significantly.
- Sales volume alone does not guarantee profitability.

## Recommendations

- Prioritize high-performing and profitable product categories.
- Review discount strategies for low-profit sub-categories.
- Improve profitability in weaker regions.
- Focus customer retention strategies on profitable customers.
- Monitor profit margins alongside sales performance.
